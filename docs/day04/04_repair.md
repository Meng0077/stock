# 4. 格式修复最多一次

实现位置：backend/examples/structured_agent.py。

## 你来完成

1. 首次完整响应发生 JSON 或 Pydantic 结构校验错误时，允许追加一次修复请求。
2. 修复请求包含原回答、所需 schema 和安全的字段/错误类别，不包含原始异常中的敏感输入。
3. 修复返回后重新执行结构校验、证据校验和 data_mode 校验，不能绕过任何检查。
4. 修复仍失败则进入明确失败终态，不再修复。
5. 修复调用占用 D03 的模型轮数预算，也受本次任务原有总时限约束；不能重置计数或计时。
6. 如果已用满模型预算，直接结束，不能额外“免费”调用一次修复。
7. 本练习只允许格式/结构错误触发修复。伪造引用、模式错误、API 错误、取消和超时不触发格式修复。
8. 拒答、截断和空正文作为单独失败，不通过修复伪装成完整回答。

## 离线验收

- 首次合法 -> 修复次数 0。
- 首次结构错误、第二次合法 -> 修复次数 1，模型调用增加 1。
- 两次均错误 -> 明确失败，不出现第三次修复请求。
- 结构正确但 E99 引用非法 -> 证据失败，修复次数 0。
- 无剩余预算或已超时/取消 -> 不发修复请求。
