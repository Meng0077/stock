# 6. 管理异步客户端生命周期

实现位置：backend/examples/structured_agent.py。

当前状态：已确认安装的 `zai-sdk==0.2.3` 仅提供同步客户端，改用
`httpx.AsyncClient` 调用官方普通对话 HTTP 接口。离线假客户端和
`httpx.MockTransport` 验证已通过；真实请求仍待 API 限额恢复后验证。

## 你来完成

1. 查已安装智谱 SDK 是否有真正的异步接口：不要仅因方法名称包含 async 就判断为 asyncio 原生异步；远端异步任务接口是另一回事。
2. 若有合适的原生异步客户端，按该版本官方说明使用；否则使用 httpx.AsyncClient 调用智谱官方 HTTP 接口。
3. 使用 HTTP 方式时，显式处理 HTTP 错误与响应解析；不能继续假设异常一定是 SDK 的 APIStatusError。
4. 在一次任务入口创建一个客户端，通过参数传入各步骤，模型多轮和格式修复复用它。
5. 使用 async with 或 try/finally 关闭客户端，成功、错误、超时、取消都应清理。
6. 保留环境变量读取和脱敏方式，不硬编码密钥；日志不记录 Authorization。
7. 不在每次请求函数里创建新客户端，也不建立模块导入即运行的全局网络请求。

## 验收

离线假客户端记录创建、请求、关闭次数：一项任务创建 1 次，所有轮次复用，最终关闭 1 次。
真实请求待 API 限额恢复后进行。`httpx==0.28.1` 已加入直接依赖声明，锁定文件版本一致。
正式 API 服务生命周期管理是后续阶段；今天只做命令行任务范围的客户端管理。
